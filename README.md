# 让民宿三维图册

可直接在手机浏览器打开的设计展示首版。页面包含 8 个可旋转的空间模型和 22 张效果图。首屏只加载网页和整栋外观；其他空间和图片从本站按需加载，不使用统计、账号、Cookie 或第三方运行时服务。

本项目按施工图和设计方案制作，用于设计展示与沟通；不是现场测绘、竣工模型、工程量清单或结构施工审核。家具、材料和未标注屋顶尺寸含已披露近似。

## 手机上查看

请用 Safari、Chrome 等现代浏览器打开网站链接。若聊天软件只显示静态预览，请选择“在浏览器打开”。模型支持旋转、缩放和空间切换；页面下方保留完整 22 张效果图。
